# 대본 작성 (P1)

`script.json` 은 이 파이프라인의 **단일 진실 공급원**이다. 길이·타이밍·카피가 여기서만 결정되고 코드는 그것을 읽을 뿐이다.

## 구조

6개 역할을 순서대로 쓴다. 전부 필수는 아니지만 **`hook` 은 정확히 1개, 반드시 첫 씬**이다.

| role | 목적 | 분량 기준 |
|---|---|---|
| `hook` | 시청자의 문제로 연다. 제품 이름을 꺼내지 않는다 | 3–5초 |
| `problem` | 손실/불편의 출처를 특정한다 | 4–6초 |
| `solution` | 해결책 제시. 여기서 처음 브랜드가 나온다 | 4–6초 |
| `how` | 사용 난이도가 낮음을 보여준다 | 5–7초 |
| `proof` | 숫자·사용처로 신뢰를 만든다 | 5–7초 |
| `cta` | 행동 지시 **하나만** | 3–5초 |

## 길이 예산

- 30초 = 5~7씬. 15초 = 3~4씬. 60초 = 8~12씬.
- 씬 최소 1.2초 (읽을 수 없는 컷 방지). 실질 하한은 2.5초 권장.
- **`durationSec × fps` 는 정수여야 한다.** 30fps 에서 4.5초는 OK(135), 4.33초는 거부된다.
- 씬 `startSec` 은 앞 씬의 끝과 정확히 같아야 한다. 구멍은 검은 프레임, 겹침은 레이아웃 충돌이 된다.

## 카피 규칙

**화면에 뜨는 글자다. 나레이션 원고가 아니다.**

- 7단어 또는 32자 이내. 넘으면 검증기가 거부한다.
- 한 씬에 한 문장, 한 주장.
- `emphasis` 는 반드시 `copy` 안에 그대로 존재하는 부분 문자열이어야 한다. 숫자를 강조하면 카운트업 모션이 자연스럽게 붙는다.
- 숫자는 구체적으로. "많은 팀" 보다 "1200팀".

### 한국어: 조사를 emphasis 에 포함시켜라

`splitEmphasis()` 는 `copy` 를 `[앞, 강조, 뒤]` 로 자른다. 조사를 빼고 자르면 **뒤 조각이 조사로 시작해 어색해진다.**

| copy | emphasis | 결과 | 판정 |
|---|---|---|---|
| `매일 3시간을 잃고 있습니다` | `3시간` | `매일` / `3시간` / `을 잃고 있습니다` | ✘ "을 잃고…" |
| `매일 3시간을 잃고 있습니다` | `3시간을` | `매일` / `3시간을` / `잃고 있습니다` | ✔ |
| `이미 1200팀이 씁니다` | `1200팀이` | `이미` / `1200팀이` / `씁니다` | ✔ |

숫자 카운트업은 `parseInt` 로 앞의 숫자만 떼어내므로 조사가 붙어 있어도 정상 동작한다 (`"3시간을"` → 숫자 3, 단위 `"시간을"`).

```jsonc
{
  "id": "hook",              // kebab-case, 유일. 파일명과 REGISTRY 키가 된다
  "role": "hook",
  "startSec": 0,
  "durationSec": 4,
  "copy": "매일 3시간을 잃고 있습니다",
  "emphasis": "3시간",       // copy 의 부분 문자열
  "intent": "충격적 통계로 문제부터 연다",   // 코드 생성 시 시각 방향 힌트. 화면에 뜰 수도 있다
  "motion": ["stagger-in", "number-countup"],  // 카탈로그의 이름만
  "exit": "fade-scale-out"
}
```

## `intent` 를 성의 있게 쓴다

`intent` 는 검증되지 않지만 **P3 코드 생성 품질을 좌우한다.** "텍스트 표시" 같은 무의미한 값 대신 그 씬이 시각적으로 무엇을 해야 하는지 쓴다. 씬마다 다른 시각 처리를 유도하는 것이 목적이다 — 같은 레이아웃 반복이 "AI 티" 나는 결과물의 주범이다.

## 세로형 / 정사각형

`meta.aspect` 를 `9:16` 이나 `1:1` 로 두고 `width`/`height` 도 맞춘다 (예: 1080×1920). 세로형은:
- 카피를 더 짧게 (5단어 이내)
- 폰트를 더 크게 (`type.display` 기준 상향)
- 세이프 에어리어를 상하로 더 확보 (UI 오버레이 회피)

## 검증

```bash
node "${CLAUDE_PLUGIN_ROOT}/scripts/validate-script.mjs" script.json
```

exit 0 전에는 코드를 쓰지 않는다. 위반 메시지는 씬 id 와 규칙 번호를 정확히 지목한다.
