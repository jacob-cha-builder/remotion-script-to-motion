# 시각 QA 루브릭 (P4)

콘택트시트를 **Read 툴로 실제로 열어본 뒤** 비트마다 아래 6항목을 본다. 하나라도 실패하면 그 씬을 고치고 재실행한다.

## 1. 가독성

| 실패 신호 | 처방 |
|---|---|
| 텍스트가 배경에 묻힘 (대비 < 4.5:1) | `palette.text` 로 올리거나 배경 글로우 `opacity` 를 낮춘다 |
| 글자가 프레임 밖으로 잘림 | `layout.maxTextWidth` 를 줄이거나 카피를 짧게 (대본 수정) |
| 세이프 에어리어(짧은 변 5%) 침범 | `SceneFrame` 이 자동 처리 — 침범했다면 씬이 `padding` 을 덮어쓴 것 |
| 폰트가 너무 작아 읽기 어려움 | `type.body` 이상 사용. `caption` 은 보조 정보 전용 |

## 2. 계층

| 실패 신호 | 처방 |
|---|---|
| 한 프레임에 동급 강조가 2개 이상 | 하나만 남기고 나머지는 `textMuted` 로 내린다 |
| 크기 단계가 4개 이상 | 3개 이하로 줄인다 |
| 어디를 봐야 할지 모르겠음 | 지배적 요소 1개를 정하고 나머지를 확실히 낮춘다 |

## 3. 구도

| 실패 신호 | 처방 |
|---|---|
| 모든 요소가 정중앙에 뭉침 | 좌정렬 또는 좌우 분할로 바꾼다 |
| 한쪽이 비어 허전함 | SVG 도형·격자·글로우로 무게를 맞춘다 |
| 3씬 연속 같은 구도 | 씬별로 정렬/지배요소를 바꾼다 (`motion-patterns.md` 하단 체크) |

## 4. 컬러 일관성

| 실패 신호 | 처방 |
|---|---|
| `tokens.ts` 에 없는 색이 보임 | `guard-tokens.mjs` 경고를 확인하고 토큰 참조로 교체 |
| 액센트가 3개 이상 등장 | warm 1 + cool 1 로 줄인다 |
| 씬마다 배경 톤이 튐 | `palette.bg` 는 고정, `glow` 만 바꾼다 |

## 5. 중간상태

25% / 75% 지점을 뽑는 이유가 이것이다. **전환 도중의 프레임이 정상으로 보여야 한다.**

| 실패 신호 | 처방 |
|---|---|
| 요소가 찌그러져 보임 (`scale` 이 극단값) | 스프링 프리셋을 `soft` 로 바꾸거나 진폭을 줄인다 |
| 25% 지점에서 아직 아무것도 안 보임 | 등장이 너무 느림 — `timing.enterSec` 을 줄이거나 stagger 간격 축소 |
| 75% 지점에서 이미 사라짐 | 퇴장이 너무 빠름 — `exitRatio` 확인 |
| 블러/투명도가 중간에 어색하게 걸림 | `clamp` 가 걸려 있는지 확인 |

## 6. 공백 / 겹침

| 실패 신호 | 처방 |
|---|---|
| 완전히 빈 프레임 | 타임라인 구멍 (대본 규칙 2 위반) 또는 등장 지연 과다 |
| 두 씬의 요소가 겹쳐 읽힘 | `Sequence` 범위 확인 — 대본의 `startSec` 이 틀렸을 수 있다 |
| 정지한 것처럼 보임 | ambient 모션(`breathe`/`drift`)이 빠졌다 |

## 판정

- **전 비트 6항목 통과** → P5 전체 렌더 진행
- **일부 실패** → 해당 씬만 수정 → `contact-sheet.mjs` 재실행
- **라운드 3회 초과** → 중단하고 남은 이슈를 사용자에게 구체적으로 보고한다. 무한 루프 금지.

## 흔한 오판

- 콘택트시트 파일이 생성됐다는 사실은 통과가 아니다. **이미지를 봐야 한다.**
- 축소본(`--scale 0.5`)에서 읽히지 않는 텍스트는 원본에서도 대체로 문제다. 애매하면 `out/qa/frames/` 의 개별 프레임을 연다.
- 한 씬이 예쁘다고 전체가 좋은 것은 아니다. **연속된 비트 사이의 변화**를 본다.
