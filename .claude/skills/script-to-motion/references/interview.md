# 인터뷰 (P1a)

대본을 쓰기 전에 **모르면 대본이 뭉개지는 것만** 묻는다. 취조가 아니다.

## 원칙

1. **최대 3문항.** 4문항이 필요하다고 느끼면 하나는 기본값으로 정할 수 있는 것이다.
2. **답할 수 있는 것만 묻는다.** "톤이 어떠셨으면 좋겠어요?" 는 사용자가 답을 발명하게 만든다. 선택지를 주고 추천을 표시한다.
3. **추측 가능한 것은 묻지 말고 채택하고 알린다.** fps 30, 다크 배경, 세이프에어리어 5% 는 기본값이다.
4. 사용자가 이미 말한 것은 다시 묻지 않는다.

## 반드시 확보해야 하는 3가지

| # | 무엇 | 없으면 생기는 일 | 기본값 |
|---|---|---|---|
| 1 | **소재** — 무엇에 대한 영상인가 | 대본을 발명하게 되고 전부 틀린다 | 없음. **반드시 묻는다** |
| 2 | **핵심 수치 1개** — 화면에 크게 뜰 숫자 | 강조할 게 없어 텍스트만 나열된다 | 없으면 소재에서 끌어낸다 |
| 3 | **길이 + 화면비** | 정보 밀도 계산이 불가능 | 30초 16:9 |

`aspect` 와 `totalSec` 이 정해지면 나머지(씬 수, 씬당 글자 예산)는 **계산되는 값이지 물어볼 값이 아니다.** §정보 밀도 참조.

## 묻지 않고 정하는 것

- fps 30 / 다크 배경 / 세이프에어리어 5% / 스프링 이징
- 씬 수 — 길이에서 계산
- 씬별 인포그래픽 — `infographic-catalog.md` 규칙으로 **추천**한다. 사용자가 뒤집을 수 있게 제시하되 먼저 정해둔다.

## 정보 밀도 (길이·화면비 → 예산)

| 길이 | 16:9 씬 수 | 9:16 씬 수 | 씬당 글자 상한 |
|---|---|---|---|
| 15초 | 3–4 | 3 | 32자 / 20자 |
| 20초 | 4–5 | 4 | 32자 / 20자 |
| 30초 | 5–7 | 4–5 | 32자 / 20자 |
| 60초 | 8–12 | 6–8 | 32자 / 20자 |

**세로형은 가로형보다 씬을 적게, 글자를 짧게 간다.** 화면이 좁아 같은 글자가 훨씬 크게 잡히고, 시청 거리가 가까워 정보 과밀이 바로 이탈로 이어진다.

세로형 추가 규칙:
- 씬당 **20자 / 5단어** 이내 (가로형 32자 / 7단어)
- 상하 12% 를 UI 오버레이 회피용으로 비운다 (세이프 5% 로 부족)
- 지배 요소는 화면 중앙 40~60% 밴드에 놓는다

## 인터뷰 후 산출물

인터뷰가 끝나면 **대본을 쓰기 전에** 사용자에게 브리프를 한 번 보여준다:

```
소재: <한 줄>
핵심 수치: <숫자> <단위>
포맷: <초>초 / <비율> / <씬 수>씬
구조: hook → ... → cta
```

여기서 어긋나면 대본 전체가 어긋나므로, 짧게라도 확인받고 넘어간다.
